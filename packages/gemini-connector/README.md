# Historical Gemini connector package

Status: superseded by ADR 0038 and scheduled for removal

This private package contains the command shell for the old separate connector
design. It has no provider adapter, support claim, or publication approval.

Do not extend or qualify this package. Gemini is outside the first Ambassador
ACP qualification scope. Any future profile needs a new accepted interface
decision under [ADR 0038](../../docs/adr/0038-ambassador-delivery-modes.md) and
the common [delivery qualification](../../docs/qualification.md).

Git history and superseded ADR 0036 retain the old evaluation.
