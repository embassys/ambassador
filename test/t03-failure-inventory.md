# Superseded T03 inventory

Status: superseded by ADR 0037 and I02

T03 specified a proposed enrollment, token, reissue, and protected central MCP
contract. It is not the current server contract and must not be preserved as a
compatibility suite.

Replace or delete the corresponding tests during I02. Current enrollment and
DPoP cases are listed in [i02-failure-inventory.md](i02-failure-inventory.md).
