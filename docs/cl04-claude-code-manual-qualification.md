# Historical Claude connector qualification

Status: superseded by ADR 0038

This runbook qualified the provider-specific Claude Code connector that is
being removed. It is not evidence for ACP direct mode or the Ambassador package
and must not be run as a current qualification.

Git history retains the original procedure. Any future Claude support must use
the common real-agent matrix in [Delivery qualification](qualification.md) and
record its ACP adapter separately.
